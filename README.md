# LearnBR – Brazilian Portuguese for Everyday Life

An interactive, gamified web platform designed for native US English speakers to learn authentic Brazilian Portuguese through real-world cultural scenarios.

---

## 🌟 Key Features

- **Language Role Inversion:** US English UI chrome (instructions, navigation, feedback) paired with rich Brazilian Portuguese educational content.
- **18 Culturally Adapted Scenarios:**
  - Family & Gatherings (*Almoço de domingo em família*)
  - Friends & Hanging Out (*Rolê com os amigos e boteco*)
  - Body Parts & Health (*Partes do corpo e farmácia*)
  - Home & Daily Chores (*Casa e a clássica faxina*)
  - Community & Neighbors (*Condomínio, eletrodomésticos e portaria*)
  - Hobbies & Samba (*Tocar violão, dançar samba e relaxar na rede*)
  - Football Culture & Sports (*Pelada na praia e Maracanã*)
  - Supermarket & Street Market (*Feira livre, pastel e caldo de cana*)
  - Shopping & Bargaining (*Compras, provador e desconto no Pix*)
  - Work & Professional Life (*Carreiras, reuniões e home office*)
  - Public Places & Getting Around (*Metrô, praças e padaria de bairro com pão na chapa e pingado*)
  - Brazilian Wildlife & Pets (*Capivara, vira-lata caramelo e tucano*)
  - Brazilian Gastronomy (*Feijoada completa, pão de queijo, coxinha e brigadeiro*)
  - Tech, Pix & WhatsApp (*Mandar áudio no Zap e pagar no Pix*)
  - Social Media & Slang (*Sextou, arrasou, tamo junto e gírias da internet*)
  - 3 Milestone Checkpoint Reviews (*Fundamentos, Imersão e Maestria*)
- **Multi-Modal Learning Tabs:**
  - **Vocabulary:** Level filters (A1, A2, B1), phonetic guides, translation toggles, and personal note-taking.
  - **Dialogue:** Authentic bilingual chat bubbles with sequential audio playback.
  - **3D Flashcards:** Interactive cards with perspective flipping, audio pronunciation, and shuffle.
  - **Gamified Quiz:** Instant visual feedback, pedagogical explanations, and score tracking with celebratory confetti.
  - **True / False Challenges:** Contextual comprehension checks.
  - **Speaking Practice:** Pronunciation guides and audio read-aloud.
  - **Reading Comprehension:** Dual-level narratives with comprehension questions.
  - **Build Sentence:** Scrambled word tile puzzles.
  - **Useful Expressions:** Deep-dives into Brazilian slang (*gírias*) and cultural idioms.
- **Native Audio Pronunciation:** Integrated browser SpeechSynthesis (`pt-BR`).
- **Progress Tracking:** LocalStorage persistence for completed scenarios and study notes.

---

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Custom Design System Tokens
- **Icons:** Lucide React
- **Typography:** Google Fonts (Fredoka)
- **Effects:** Canvas Confetti

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/mantolatv-cmyk/LearnBR.git
cd LearnBR
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
